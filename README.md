# Summtra - Find Your Lucky City 🧭✨

A beautiful PWA that helps users discover their lucky cities based on astrocartography - the ancient science of location astrology powered by modern NASA-grade calculations.

![Summtra Preview](icons/icon-512x512.png)

## Features

- 🌍 **India + Worldwide** - Search for lucky cities within India or globally
- 🛰️ **NASA-Grade Accuracy** - Swiss Ephemeris precision calculations
- 📱 **Mobile-First PWA** - Install on any device like a native app
- ✨ **Beautiful UI** - Night sky background with twinkling stars
- 🔥 **Conversion Optimized** - Social proof, testimonials, urgency elements

## Tech Stack

- Pure HTML, CSS, JavaScript (no frameworks)
- Progressive Web App (PWA)
- Service Worker for offline support
- Responsive mobile-first design

## Getting Started

### Run Locally

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/summtra.git
cd summtra
```

2. Serve the files (use any static server):
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

3. Open `http://localhost:8000` in your browser

### Deploy on Replit

1. Import from GitHub on Replit
2. Set as Static HTML project
3. Click Run!
