FILE: templateProcessor.js

ADD HELPER FUNCTION (near top of file with other helpers):
```javascript
// Helper function for a/an grammar
function getArticle(word) {
  if (!word) return 'a';
  const vowels = ['A', 'E', 'I', 'O', 'U'];
  return vowels.includes(word.charAt(0).toUpperCase()) ? 'an' : 'a';
}
```
