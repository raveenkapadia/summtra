### ISSUE 1: Add Yogakaraka to Goal Planets

**Problem:** 
For Taurus Lagna, Yogakaraka is Saturn.
But Saturn is NOT in Wealth goal planets (Jupiter, Venus, Mercury, Sun).
So Taurus users never see their most beneficial planet.

**Solution:**
When user has a Yogakaraka, ADD that planet to their personal goal planets.
```javascript
function getPersonalGoalPlanets(goal, lagna) {
  // Base goal planets
  const baseGoalPlanets = {
    'Wealth': ['Jupiter', 'Venus', 'Mercury', 'Sun'],
    'Career': ['Sun', 'Saturn', 'Jupiter', 'Mercury'],
    'Love': ['Venus', 'Moon', 'Mars', 'Jupiter'],
    'Education': ['Mercury', 'Jupiter', 'Moon', 'Sun'],
    'Settlement': ['Moon', 'Venus', 'Saturn', 'Jupiter'],
    'Complete': ['Jupiter', 'Venus', 'Sun', 'Moon', 'Mercury', 'Saturn', 'Mars']
  };
  
  let personalPlanets = [...baseGoalPlanets[goal]];
  
  // Add Yogakaraka if exists and not already in list
  const yogakaraka = YOGAKARAKA_BY_LAGNA[lagna];
  if (yogakaraka && !personalPlanets.includes(yogakaraka)) {
    personalPlanets.push(yogakaraka);
  }
  
  return personalPlanets;
}
```

**Example:**
- Taurus Lagna + Wealth Goal
- Base: [Jupiter, Venus, Mercury, Sun]
- Yogakaraka: Saturn
- Personal: [Jupiter, Venus, Mercury, Sun, **Saturn**]

Now Saturn lines will appear for Taurus users!

### ISSUE 3: Updated Boost Calculation

**New Logic:**
```javascript
function getPersonalizedPlanetMultiplier(planet, lagna, mahadasha) {
  const wealthLords = WEALTH_LORDS_BY_LAGNA[lagna];
  const yogakaraka = YOGAKARAKA_BY_LAGNA[lagna];
  const functionalStatus = FUNCTIONAL_STATUS_BY_LAGNA[lagna];
  
  let multiplier = 1.0;
  
  // 1. Natural wealth planets (Jupiter, Venus)
  if (['Jupiter', 'Venus'].includes(planet)) {
    multiplier *= 1.10;
  }
  
  // 2. Personal 2nd house lord (wealth)
  if (planet === wealthLords.secondLord) {
    multiplier *= 1.20;
  }
  
  // 3. Personal 11th house lord (gains)
  if (planet === wealthLords.eleventhLord) {
    multiplier *= 1.15;
  }
  
  // 4. Yogakaraka (most beneficial planet)
  if (yogakaraka && planet === yogakaraka) {
    multiplier *= 1.35;
  }
  
  // 5. Mahadasha Lord - BUT CHECK IF BENEFIC OR MALEFIC
  if (mahadasha && mahadasha !== 'Rahu' && mahadasha !== 'Ketu') {
    if (planet === mahadasha) {
      // Check if Mahadasha planet is benefic or malefic for this Lagna
      if (functionalStatus.benefics.includes(mahadasha)) {
        multiplier *= 1.15;  // Boost for benefic Mahadasha
      } else if (functionalStatus.malefics.includes(mahadasha)) {
        multiplier *= 0.85;  // PENALTY for malefic Mahadasha
      }
    }
  }
  
  // 6. General functional malefic penalty (even if not Mahadasha)
  if (functionalStatus.malefics.includes(planet)) {
    multiplier *= 0.90;  // Slight penalty for malefic planets
  }
  
  return multiplier;
}
```
