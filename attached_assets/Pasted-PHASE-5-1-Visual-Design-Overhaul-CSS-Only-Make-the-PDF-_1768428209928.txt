PRIORITY 2: SPACING & BREATHING ROOM
═══════════════════════════════════════════════════════════════

Current problem: Everything feels cramped and dense.

FIXES:

1. PAGE MARGINS
   - Increase page padding: 60px on all sides (was ~30px)
   - Content should not touch edges

2. SECTION SPACING
   - Add 40px margin between major sections
   - Add 24px padding inside section boxes

3. LINE HEIGHT
   - Body text: line-height: 1.7 (was ~1.4)
   - Headers: line-height: 1.3

4. PARAGRAPH SPACING
   - margin-bottom: 16px between paragraphs
   - Don't stack text blocks without breathing room

5. TABLE/GRID SPACING
   - Cell padding: 16px (was ~8px)
   - Row spacing: 12px gap

CSS Example:
```css
.section {
  margin-bottom: 48px;
  padding: 32px;
}

.content-block {
  margin-bottom: 24px;
  line-height: 1.7;
}

.city-card {
  padding: 24px;
  margin-bottom: 20px;
}
```
