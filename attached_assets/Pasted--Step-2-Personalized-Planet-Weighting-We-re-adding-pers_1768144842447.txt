### PART 3: Boost Rules

For each planet, check these conditions. Multiply all matching boosts together:

| Condition | Multiply By |
|-----------|-------------|
| Planet is Jupiter OR Venus | ×1.10 |
| Planet = User's 2nd Lord | ×1.25 |
| Planet = User's 11th Lord | ×1.20 |
| Planet = User's Yogakaraka | ×1.30 |
| Planet = User's Mahadasha | ×1.15 |

SKIP Mahadasha boost if Mahadasha is Rahu or Ketu.

---

### PART 4: How to Calculate

Step 1: Get user's Lagna from Vedic API
Step 2: Look up their 2nd Lord from Table 1
Step 3: Look up their 11th Lord from Table 1
Step 4: Look up their Yogakaraka from Table 2
Step 5: Get user's Mahadasha from Vedic API

Step 6: For each planet, calculate total boost:
- Start with 1.0
- Multiply by 1.10 if planet is Jupiter or Venus
- Multiply by 1.25 if planet matches 2nd Lord
- Multiply by 1.20 if planet matches 11th Lord
- Multiply by 1.30 if planet matches Yogakaraka
- Multiply by 1.15 if planet matches Mahadasha (skip if Rahu/Ketu)

Step 7: Apply boost to line score:
- Adjusted Line Score = Base Line Score × Boost
- Cap at maximum 35

Step 8: Normalize Western Total:
- Western Total = Adjusted Line Score + Paran Score
- Western Normalized = (Western Total ÷ 60) × 50
